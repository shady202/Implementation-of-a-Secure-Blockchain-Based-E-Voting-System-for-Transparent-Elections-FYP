# Voter Workflow - Generalized Process

## **Complete Voter Journey**

### **Phase 1: System Preparation**

1. Install Digital Wallet
2. Configure Blockchain Network
3. Obtain Transaction Funds

### **Phase 2: Account Creation**

4. Access Registration Page
5. Enter Personal Information
6. Submit Registration
7. Receive Verification Code
8. Verify Email Address
9. Account Activated

### **Phase 3: Wallet Registration**

10. Connect Digital Wallet
11. Approve Wallet Connection
12. Register Voter on Blockchain
13. Confirm Blockchain Transaction
14. Wallet Bound to Account

### **Phase 4: Authentication**

15. Enter Login Credentials
16. Verify Identity (OTP)
17. Receive Session Token
18. Access Granted

### **Phase 5: Casting Vote**

19. Verify Election Active
20. Browse Candidates
21. Select Candidates
22. Submit Vote
23. Approve Transaction
24. Vote Recorded on Blockchain
25. Receive Confirmation

### **Phase 6: Verification**

26. View Vote Status
27. Check Blockchain Record
28. View Election Results

---

## **Key Verification Points**

### **Wallet Interactions:**

- Connection Request
- Network Verification
- Transaction Approval
- Signature Confirmation

### **Identity Checks:**

- Email Verification
- Password Authentication
- Wallet Ownership
- Session Validation

### **Access Requirements:**

- Registered Account
- Active Session
- Connected Wallet
- Active Election
- Single Vote Per Election

---

## **System Flow States**

**Voter:** Unregistered → Registered → Authenticated → Voted

**Election:** Setup → Standby → Active → Ended

**Wallet:** Disconnected → Connected → Verified → Signed
