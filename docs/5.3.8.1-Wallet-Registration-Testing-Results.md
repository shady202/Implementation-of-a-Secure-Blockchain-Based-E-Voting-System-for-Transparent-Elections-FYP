## Test Results

### 5.1 Connect MetaMask Wallet (First-Time User)

**Actual Result:** System automatically redirects to Wallet Registration page after successful login (if wallet not registered), user clicks "Connect MetaMask" button, MetaMask popup appears, wallet connects successfully, wallet address displayed on page with truncated format.

**Status:** ✅ **Pass**

---

### 5.2 Register Wallet with User Account

**Actual Result:** Wallet address registered on blockchain with student details (student_id, department, year), wallet address stored in PostgreSQL database linked to student_id, success message displayed, permanent wallet-to-student binding created on both blockchain and database.

**Status:** ✅ **Pass**

---

### 5.3 Attempt to Register Second Wallet

**Actual Result:** Amber alert displayed showing "Wallet Already Registered" with registered wallet address, registration form hidden, "Go to Vote Page" button shown, duplicate registration prevented.

**Status:** ✅ **Pass**

---

### 5.4 Register Wallet Used by Another Student

**Actual Result:** "Wallet Address Mismatch" alert displayed with security warning, message states "This wallet address has been registered before with a different account. Please choose a new wallet", instructions provided to switch wallet in MetaMask, registration prevented, "Refresh Page" and "Return Home" buttons shown.

**Status:** ✅ **Pass**

---

### 5.5 Wallet Address Format Validation

**Actual Result:** Wallet address retrieved via `signer.getAddress()` using EIP-1193 standard, MetaMask guarantees valid format (0x + 40 hex), no manual input, validation automatic.

**Status:** ✅ **Pass** (N/A - Automatic validation by MetaMask)

---

### 5.6 Registration Without MetaMask

**Actual Result:** Error message "MetaMask is not installed" displayed with red alert, "Connect MetaMask" button disabled, download link provided, registration blocked until MetaMask installed.

**Status:** ✅ **Pass**

---

### 5.7 Complete Voter Registration

**Actual Result:** Voter record created in database with student_id, wallet_address, department, and year_of_study, all required fields stored correctly, registration timestamp recorded.

**Status:** ✅ **Pass**

---

### 5.8 Database Wallet Uniqueness Constraint

**Actual Result:** Database constraint violation prevented duplicate wallet addresses, attempt to insert duplicate wallet rejected, error message displayed to user, data integrity maintained.

**Status:** ✅ **Pass**
